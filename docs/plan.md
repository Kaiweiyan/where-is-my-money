# Where's My Money? — 未來計畫

> 這份文件只放**還沒定案**的提案。提案定案後，從這裡移除，並把設計寫進 [spec.md](spec.md)；過程和完成的步驟記在 [CHANGELOG.md](CHANGELOG.md)。

## 技術方向（預設，開工前可再調整）

| 項目 | 選擇 |
|---|---|
| 語言 / UI | Kotlin + Jetpack Compose（Material 3） |
| 架構 | 單一 `app` module 起步，MVVM + 單向資料流（UI ← StateFlow ← ViewModel ← Repository） |
| 本機資料庫 | Room（SQLite），搭配 Coroutines / Flow |
| 設定值 | DataStore（Preferences） |
| 導覽 | Navigation Compose |
| 依賴注入 | Hilt |
| 建置 | Gradle Kotlin DSL + version catalog（`libs.versions.toml`），在 WSL 用 command-line Android SDK 建置 |
| 資料範圍 | 只存本機，不做帳號、不連網路 |
| Python | 不需要；之後若有輔助腳本再用 uv + Python 3.12 |

## 已決定，待寫入 spec.md

- 金額用 `Long` 存最小貨幣單位（TWD 就是「元」），不用 `Double`
- 幣別：TWD
- 一週起始日：星期一或星期日，由使用者選擇（見 J1）

## 功能清單

標 **【第一批】** 的是先做的：A1、A2、B1、B2、B3、C1、C2。

### A. 記帳核心

- [ ] **A1 新增紀錄** 【第一批】：金額、收入 / 支出、分類、日期時間、備註
- [ ] **A2 編輯 / 刪除** 【第一批】：刪除後可用 Snackbar 復原
- [ ] **A3 轉帳**：帳戶之間移動錢（提款、繳卡費），不算收支
- [ ] **A4 複製一筆**：從舊紀錄一鍵帶入，只改金額
- [ ] **A5 計算機鍵盤**：金額欄可直接輸入 `120+35`
- [ ] **A6 拆分紀錄**：一張發票拆成多個分類
- [ ] **A7 收據照片**：附加照片，存本機
- [ ] **A8 標籤**：跨分類標記，例如 #日本旅行
- [ ] **A9 商家欄位**：記錄消費地點，可自動補完

### B. 分類與帳戶

- [ ] **B1 預設分類** 【第一批】：餐飲、交通、購物、居住、娛樂、醫療、薪資…
- [ ] **B2 自訂分類** 【第一批】：新增、改名、圖示、顏色、排序、封存
- [ ] **B3 子分類** 【第一批】：兩層，例如 餐飲 → 早餐 / 午餐 / 飲料
- [ ] **B4 多帳戶**：現金、銀行、信用卡、電子支付、悠遊卡
- [ ] **B5 帳戶餘額**：設定初始餘額，自動算出目前餘額
- [ ] **B6 信用卡帳戶**：結帳日、繳款日、本期未繳金額
- [ ] **B7 不計入統計**：某些帳戶或紀錄不算進收支（例如代墊）
