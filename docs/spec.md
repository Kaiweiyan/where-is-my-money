# Where's My Money? — Spec

> **每次實作前請先閱讀這份檔案。**

## 專案規則

1. 所有檔案要更動前，必須先達成明確的共識。
2. 必須先在這份檔案完成說明，才可開始對應撰寫程式碼。
3. 每次實作前先 `git pull` 確認更新後再開始。
4. 這份檔案只寫現在的設計。過程和已完成的步驟放 `docs/CHANGELOG.md`；還沒定案的提案放 `docs/plan.md`。
5. 所有檔名與資料夾名稱一律使用英文。
6. 改設計時，要搜尋整份檔案裡提到同一件事的地方，一起改掉或刪掉，不可以只在新位置加一段。
7. 功能做完並試過之後，回頭清理這份檔案：刪掉實作順序和「尚未實作」的狀態，更新「先不做的」清單。
8. Commit 訊息一律依照 `docs/git-style.md` 的格式。

## 目前設計

### 金額與幣別

- 幣別固定為 TWD。
- 金額以 `Long` 存最小貨幣單位（TWD 為「元」），不使用 `Double` / `Float`，避免浮點誤差。

- 畫面顯示為 `$` 加千分位，例如 `$1,234`。

### 一週起始日

- 使用者可選擇星期一或星期日。（尚未實作，設定畫面見 `plan.md` J1）

### 第一批範圍與實作順序（尚未實作）

範圍：A1 新增紀錄、A2 編輯 / 刪除、B1 預設分類、B2 自訂分類、B3 子分類、C1 首頁總覽、C2 紀錄清單。

1. 資料模型與預設分類（B1）
2. 新增紀錄（A1）
3. 首頁總覽與紀錄清單（C1、C2）
4. 編輯與刪除紀錄（A2）
5. 分類管理（B2、B3）

### 資料模型

**Category（分類）**

| 欄位 | 型別 | 說明 |
|---|---|---|
| `id` | Long | 主鍵 |
| `type` | `EXPENSE` / `INCOME` | 建立後不能改 |
| `name` | String | 1–12 字，同一層不可重名 |
| `icon` | String? | 只有上層分類有 |
| `color` | Int? | 只有上層分類有 |
| `parentId` | Long? | `null` 代表上層分類 |
| `sortOrder` | Int | 同一層內的順序 |
| `isArchived` | Boolean | 是否封存 |

**Record（紀錄）**

| 欄位 | 型別 | 說明 |
|---|---|---|
| `id` | Long | 主鍵 |
| `type` | `EXPENSE` / `INCOME` | 一定等於所屬分類的 `type` |
| `amount` | Long | 單位「元」，1 ～ 999,999,999 |
| `categoryId` | Long | 可以是上層分類或子分類 |
| `occurredAt` | Long | 發生時間（epoch 毫秒） |
| `note` | String | 選填，最多 100 字 |
| `createdAt` / `updatedAt` | Long | 建立、修改時間 |

- 資料表命名為 `Record`，避開 SQL 保留字 `transaction` 和 Room 的 `@Transaction`。

### 首頁（C1、C2）

- 頂部 app bar：標題「Where's My Money?」，右側分類管理按鈕。
- 總覽卡：月份切換（左右箭頭），顯示當月收入、支出、結餘（收入 − 支出）。結餘為負時用錯誤色（紅）。
- 期間為自然月。
- 紀錄清單依日期分組，新到舊。日期標題格式「11月22日 星期日」，今天、昨天前面加「今天 · 」「昨天 · 」；標題右側顯示當天支出、收入小計（沒有的那項不顯示）。
- 每筆紀錄顯示：上層分類的圖示與顏色、「上層 · 子分類」名稱、備註（單行，過長截斷）、金額。支出顯示 `−$120`，收入顯示收入色（綠）的 `+$3,000`。分類已封存時名稱後加「已封存」標籤。
- 當月沒有紀錄時顯示空狀態：「N 月還沒有紀錄」「按右下角的 + 記第一筆」。
- 點一筆紀錄進入編輯；右下角 FAB（+）進入新增。

### 新增 / 編輯紀錄（A1、A2）

- 全螢幕頁面。app bar：左側關閉、標題（新增紀錄 / 編輯紀錄）、編輯時才有的刪除按鈕、右側「儲存」。
- 支出 / 收入切換：切換時清掉已選的分類。
- 金額：顯示在切換列下方，靠右、大字、千分位；收入時用收入色。
- 金額用自訂數字鍵盤輸入（1–9、0、00、退格、儲存），只收整數，最多 9 位數，不接受開頭的 0。
- 分類：格狀列出目前收支類型、未封存的上層分類，最後一格「管理」可跳到分類管理（返回時已填內容保留）。點有子分類的上層後，下方出現子分類 chips，第一個是「不指定」（直接記在上層分類）。
- 日期時間：預設為現在，用 Material DatePicker 與 TimePicker 修改。
- 備註：選填，最多 100 字，儲存時去掉前後空白。
- 金額為 0 或未選分類時，「儲存」不能按，並在下方提示缺什麼。
- 儲存後回到首頁，首頁切到該筆紀錄所在月份，顯示 Snackbar「已新增一筆紀錄」/「已儲存」。
- 刪除：直接刪除並回到首頁，Snackbar「已刪除一筆紀錄」附「復原」，5 秒內可復原。
- 編輯一筆分類已封存的紀錄時，該分類仍顯示並保持選取。

### 分類管理（B1、B2、B3）

- 從首頁 app bar 或記帳頁的「管理」進入。從記帳頁進入時，預設顯示該筆紀錄的收支類型。
- 支出 / 收入分頁。清單列出上層分類（圖示、名稱、子分類數、紀錄筆數），子分類縮排列在底下（上層顏色的小圓點、名稱、筆數）。
- 已封存的分類收在清單底部「已封存（N）」，可展開。
- app bar 右側 + 新增分類。點任一分類開啟編輯 bottom sheet：
  - 名稱：1–12 字，同一類型、同一層不可重名。
  - 上層分類：「無（這是上層分類）」或選一個上層分類。底下已有子分類的分類不能改成子分類。
  - 圖示與顏色：只有上層分類可選；子分類沿用上層的圖示與顏色。
  - 排序：在清單上長按拖曳，只能在同一層內移動。
  - 封存 / 取消封存：封存後記帳時選不到，舊紀錄照常顯示。封存上層分類時，子分類一併隱藏。附 Snackbar 復原。
  - 刪除：只有沒有任何紀錄、也沒有子分類時才能刪，否則按鈕停用並提示改用封存。附 Snackbar 復原。
- 子分類改為上層分類時，給預設圖示與顏色；改變層級時排到新的那一層最後面。
- 預設分類和自訂分類一樣可改名、換圖示、封存、刪除。
